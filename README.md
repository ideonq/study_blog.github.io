## 📌 About

안녕하세요! 컴퓨터공학을 전공하며 배우고 경험하는 기술들을 체계적으로 정리하는 공간입니다.

강의실에서 배운 이론부터 실습 프로젝트, 그리고 개인적으로 탐구한 기술까지 모든 학습 과정을 기록하고 있습니다. 이 저장소는 단순한 노트를 넘어서, 제 성장의 타임라인이자 같은 길을 걷는 분들과 지식을 공유하는 플랫폼이 되길 바랍니다.

## 🎯 목표

- **체계적인 학습**: 배운 내용을 구조화하여 정리
- **지속적인 성장**: 꾸준한 기록을 통한 실력 향상
- **지식 공유**: 학습한 내용을 다른 사람들과 나눔
- **포트폴리오 구축**: 학습 과정과 결과물 아카이빙
